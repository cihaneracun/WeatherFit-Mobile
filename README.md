# 🌦️ WeatherFit Mobile

React Native ve Expo kullanılarak geliştirilmiş, anlık hava durumu verilerini sunan modern bir mobil uygulama projesidir.

## 🚀 Proje Hakkında
Bu uygulama, **OpenWeather API** entegrasyonu ile kullanıcının belirlediği şehrin hava durumu verilerini (sıcaklık, nem, rüzgar hızı vb.) gerçek zamanlı olarak çeker ve kullanıcı dostu bir arayüzle sunar.

### 🛠️ Kullanılan Teknolojiler
* **Frontend:** React Native (Expo)
* **Dil:** TypeScript / JavaScript
* **API Entegrasyonu:** Axios
* **Veri Kaynağı:** OpenWeatherMap API

## 📋 Özellikler
* Şehir bazlı anlık hava durumu sorgulama.
* Dinamik ikonlar ve arka plan (Hava durumuna göre).
* Hata yönetimi (Error Handling) ve yükleme durumu (Loading state).

## ⚙️ Kurulum
Projeyi yerelde çalıştırmak için:
1. `git clone https://github.com/cihaneracun/WeatherFit-Mobile.git`
2. `npm install`
3. `npx expo start`
